Circle Feature: Circle around Biel, Switzerland¶

The following notebook demonstrates the full workflow to access, process and visualize ICON-CH1-EPS model data in a circle around the swiss City Biel using total precipitation data.

The data is retrieved using Polytope, a feature extraction software developed by ECMWF. It applies concepts of computational geometry to extract n-dimensional polygons (also known as polytopes) from datacubes, such as a bounding box. Follow the instructions to learn more about model data access via Polytope.

Installation¶

Follow the instructions in README.md to install the necessary dependencies.

Configuring Access to Polytope¶

To access ICON data via MeteoSwiss's Polytope, you need a Polytope offline token provided by MeteoSwiss. If you do not already have a token, you can request one here. Then, create a new config.yml file based on config_example.yml, and replace <meteoswiss_key> with your access token there.

In [1]:
import os
import yaml

def load_config(path="config.yml"):
    if not os.path.exists(path):
        raise FileNotFoundError("Missing config.yml. Please create one based on config_example.yml.")
    with open(path, "r") as f:
        return yaml.safe_load(f)

config = load_config()

#ICON-CSCS Polytope credentials
os.environ["POLYTOPE_USER_KEY"] = config["meteoswiss"]["key"]
os.environ["POLYTOPE_ADDRESS"] = "https://service.meteoswiss.ch/polytope"

Selecting date and time of the forecast¶

The FDB containing real-time data typically holds only the most recent day of forecasts. Therefore, it is necessary to specify the current date and select a corresponding forecast time in the past.

In [2]:
from datetime import datetime, timedelta

# Current time
now = datetime.now()

# Subtract 12 hours
past_time = now - timedelta(hours=12)

# Round down to the nearest multiple of 6
rounded_hour = (past_time.hour // 6) * 6
rounded_time = past_time.replace(hour=rounded_hour, minute=0, second=0, microsecond=0)

# Format as YYYYMMDD and HHMM
date = rounded_time.strftime('%Y%m%d')
time = rounded_time.strftime('%H%M')
date,time

Define the circle center¶

In our example we are looking for a bounding box covering Switzerland. Therefore, we need to select two points. The first corresponding to the upper left and the second matching the bottom right corner of the bounding box.

In [3]:
center = [[7.25, 47.15]] # Biel City

Define the request¶

We need to define a MARS request. The feature attribute allows you to extract only the relevant data at the given points. Thus, the amount of data that is retrieved from storage is significantly reduced. For the "bounding box" feature the following dictionary is needed.

NOTE: Don't forget to specify that the data points are tuples that first contain longitude and then latitude.

In [4]:
feature={
        "type": "circle",
        "center": center,
        "axes": ["longitude", "latitude"],
        "radius": 0.1,
}

Finally, we can define the request. This example fetches total precipitation from ICON-CH1-EPS at the surface, for the control forecast (type="cf"), at the selected run date/time.

In [ ]:
request = {
    'param': 'TOT_PREC',
    'date': date,
    'time': time,
    'expver': '0001',
    'step': [6,7,8,9,10],
    'class': 'od',
    'levtype': 'sfc',
    'model': 'icon-ch1-eps',
    'stream': 'enfo',
    'type': 'cf',
    'feature': feature,
    'timespan': 'fs' # from start: means the data is accumulated from the forecast reference time
}

Disaggregating Precipitation¶

The precipitation data is aggregated from the forecast reference time (see last key in the request above: 'timespan' : 'fs'), meaning each hourly forecast value represents the amount of precipitation from hour 0 up to the given lead time. To convert precipitation accumulated over the whole forecast time into one-hour precipitation, we use the deaccumulate() function provided by the temporal module in earthkit-transforms.

In [7]:
import earthkit.transforms.temporal as temporal

deaccumulated_forecast = temporal.deaccumulate(
    ds, time_dim= "steps",
    accumulation_type="start_of_forecast"
    )

Plotting¶

We use the library earthkit.plots to plot the data. Moreover, we can specify a styling with earthkit.plots.styles to show a color spectrum from red to blue and convert the unit to Celsius for better readability.

In [8]:
from earthkit.plots import Figure
from earthkit.plots.styles import Style
from earthkit.plots.styles.levels import Levels
from earthkit.plots.geography import bounds, domains
import cartopy.crs as ccrs
import matplotlib.ticker as mticker

xmin, xmax = 7, 7.5   # Longitude bounds
ymin, ymax = 47, 47.3   # Latitude bounds

bbox = bounds.BoundingBox(xmin, xmax, ymin, ymax, ccrs.Geodetic())
domain = domains.Domain.from_bbox(bbox=bbox, name="Biel")

style = Style(
    colors="GnBu",
)

steps = deaccumulated_forecast["steps"].values
 
figure = Figure(rows=2, columns=2)

for step in steps:
    chart = figure.add_map(domain=domain)
    chart.contourf(deaccumulated_forecast.sel(steps=step), x="longitude", y="latitude", style=style)

    chart.coastlines()
    chart.borders()
    chart.cities("high")
    chart.gridlines()
    
    chart.title(f"Lead time: {int(step)}h")

figure.title("Circle: Total precipitation at {datetimes}")
figure.legend(label="Total Precipitation (mm/h)")
figure.show
